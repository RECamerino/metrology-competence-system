summary: >-
  Telling three properties apart that ordinary English treats as one. An
  instrument can have any combination of them, and every combination occurs on
  a real bench: a six-digit display with a failed reference, a meter that reads
  the same wrong value all day, a noisy instrument whose average is right.
  Nothing later in this discipline works if these three are held as a single
  idea called being good, and the confusion survives into careers because
  nobody is ever asked to separate them out loud.

  1: >-
    Given three described situations — readings that scatter widely around the
    correct value, readings that agree closely with each other and are all
    wrong by the same amount, and a display that shows only whole units —
    identifies which of accuracy, precision and resolution each situation is
    about, and names the property each situation says nothing about.
  2: >-
    For a supplied instrument specification together with a set of readings

    from the reference value to accuracy. Contrasts two instruments where the
    one with the finer display is the less accurate, and explains why repeating
    a measurement helps in one of the three cases and not in the others.

Notes for assessors and item authors. The subject is explained in `BOK-0005`
§s01 — do not restate it here.

**This is a `knowledge` element and the anchors describe explanation, not
performance.** Computing anything from a specification is `DP-08-064`. What is
assessed here is whether the candidate can hold the three apart and say what
each one does not tell you.

**No prerequisites, deliberately.** This is a foundational element in the sense
of rule 13 — it is where the discipline starts, and requiring anything before
it would reintroduce exactly the entry barrier the foundational areas exist to
remove.

**Where candidates fail.** Treating resolution as a proxy for accuracy, which
is the error the whole element exists to prevent and which a six-digit handheld
encourages. Using "precise" to mean "accurate", so a stable systematic offset
is described as good performance. Believing that repeating a measurement
improves all three — it addresses precision, does nothing for a systematic
error, and cannot alter resolution.

**The ceiling is 2 and that is not a shortfall.** There is no unaided-novel-case
version of distinguishing three definitions, and no non-routine case a
procedure fails to cover. An L3 here would be an invented rung. The depth in
this area lives in the elements that *use* the distinction.

**Every role target is 2, and that is honest rather than lazy.** Where this
element is in a person's deployment scope there is no role that needs less than
the ceiling — a technician who cannot separate these should not be reading a
meter, and an assessor who cannot is not assessing. No role can be `null`
either, because there is no deployment in which the element could never apply
if DP-08 is in scope at all. This is worth noticing as a property of
ceiling-2 foundational elements generally, not as a fact about this one.
