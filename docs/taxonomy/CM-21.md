# CM-21 — Artificial Intelligence and Machine Learning in Metrology

[← All domains](README.md)

> Using, building and critically evaluating AI and ML systems where they touch measurement. Present as a KNOWLEDGE DOMAIN only — this project ships no AI in its own product, deliberately, because hallucinated guidance must never reach a user whose output becomes accreditation evidence. That decision does not excuse practitioners from understanding these systems: they are already embedded in instruments, inspection systems and the workflows of every metrologist. Boundary: the statistics are CM-05; software practice is CM-14; uncertainty of ML-derived results is CM-03-103.

## CM-21-A07 — Generative AI, Assisted Engineering and Model Provenance

> Generative systems break assumptions that the rest of this domain relies on: the same input does not give the same output, the model behind an interface changes without notice, and a fluent answer carries no signal about whether it is grounded. A measurement result touched by such a system needs to record which model produced it, not merely which software version — a distinction that does not yet exist in most provenance models and will have to.
