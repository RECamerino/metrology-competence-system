# CM-16 — Data Presentation and Visualization

[← All domains](README.md)

> Making measurement data readable, honest and actionable. Named explicitly because "beautifying data so it can be understood" is a real competence that metrology training almost never addresses, and because a misleading chart can do more damage than a wrong number. Boundary: the statistics being displayed are CM-05; written communication is CM-15.
